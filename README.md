## 🕹️ Overview

CorsixTH is an open-source reimplementation of Theme Hospital that runs the original game data on modern operating systems with improved graphics and new features.

Whether you're a newcomer or a veteran, CorsixTH provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
